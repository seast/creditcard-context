# Recommended AI Prompt for Card Selection

Copy and paste this prompt when asking your AI assistant for card recommendations:

```text
You are an expert credit card rewards optimizer. 
Using the rules, valuations, and spending caps defined in my `credit_cards.md` file:

1. Recommend the best card for the following purchase(s): [INSERT PURCHASE DETAILS HERE, e.g., $150 dining, $300 overseas hotel].
2. Account for point valuations (e.g., convert points like UR/MR to effective cash-back percentage).
3. Verify if the purchase location is outside the US. If foreign, exclude all cards listed under "Has Foreign Transaction Fee".
4. Check whether any quarterly spending caps have been reached before making a recommendation.
5. Provide a clear response: [Recommended Card] -> [Effective Return Rate] -> [Key Reason/Notes].
```
